Паспорта изделий—

1. Загрузка коммерческого предложения

Скрипт перебирает все листы и находит таблицы изделий.

1b. Если автопарсинг не сработал — вставьте таблицу вручную

Это работает всегда: скрипт разберёт таблицу по разделителям табуляции.

1c. Загрузка «Таблицы изделий»

Ищутся колонки: «Название файла», «Номер для бухгалтерии», «Название как в заявке», «Объём, см³», «Масса, г», «Количество, шт».

2. Общие параметры

Используется для номера паспорта (ГГММДД) и номера партии (ДДММГГ)
Если выключить — на паспорте останется пустая линия для подписи от руки

2b. Параметры заказа на производство

Обязательное поле — без него формирование XLSX невозможно.
Если оставить пустым — подставляется значение из паспортов (ДДММГГ-N).
Если включить — появится поле для ввода граммов брака.

3. Групповые операции

Партия изделий №:—
Изделий в списке:0

4. Сохранение / восстановление сессии

Файл JSON также автоматически добавляется в ZIP-архив.
